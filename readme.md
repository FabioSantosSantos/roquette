# Roquette Pinto – Jogo Educativo sobre a História do Rádio

## Visão Geral

Este projeto é um jogo educativo desenvolvido em JavaScript puro utilizando HTML5 Canvas.

Seu objetivo é ensinar História do Rádio através de perguntas e respostas, permitindo que o aluno avance na história conforme responde corretamente.

Todo o projeto foi desenvolvido sem frameworks, tornando-o ideal para uso didático em escolas e universidades.

O código foi escrito para ser facilmente adaptado por professores, permitindo modificar:

- perguntas;
- alternativas;
- respostas corretas;
- música;
- efeitos sonoros;
- personagem;
- cenário;
- fontes;
- cores;
- velocidade;
- tamanho dos elementos;
- interface.

---

# Tecnologias

O projeto utiliza apenas tecnologias nativas do navegador.

- HTML5
- CSS3
- JavaScript ES6
- HTML Canvas
- Web Audio API

Não existe necessidade de instalar bibliotecas.
